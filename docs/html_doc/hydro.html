max_cost(week: int) → float

Compute a conservative maximum cost for a given week.

For each scenario at the given week, this inspects the interpolated cost function c_w^s(u) at the two extreme control values available in its grid (controls[0] and controls[-1]), and returns the minimum over both extremes and all scenarios:

min_cost = min_s min( c_w^s(u_min), c_w^s(u_max) )

Parameters:

week (int) – Week index.

Returns:

minimum cost of the stage cost for the given week across scenarios.
